# 협력업체 정기평가 개요

## 1. 목적

협력업체 정기평가는 거래 중인 협력업체의 품질, 납기, 신용, SHE, 기술/협업 수준 등을 종합적으로 평가하여 업체 등급을 산정하고 거래 리스크를 관리하기 위한 업무이다.

정기평가는 단순한 점수 입력 업무가 아니라 다음 요소가 결합된 구조이다.

- 평가계획
- 평가대상 업체 선정
- 평가영역별 평가 수행
- 점수 수집 및 환산
- 최종등급 산정
- 평가결과 확정
- 업체 등급 반영

## 2. 핵심 개념

협력업체 정기평가는 LMS/학사관리 구조와 유사하게 이해할 수 있다.

| LMS/학사관리 | 협력업체 평가 |
|---|---|
| 학생 | 협력업체 |
| 학기 | 평가차수 |
| 과목 | 평가영역 |
| 시험 | 평가수행 |
| 문항 | 평가항목 |
| 배점 | 항목점수 |
| 학점비율 | 가중치 |
| 성적처리 | 환산점수 계산 |
| 최종등급 | 업체등급 |
| 수료/탈락 | 거래유지/제한 |

## 3. 정기평가 구조

```text
정기평가
  └─ 평가영역
      └─ 평가항목
          └─ 배점 / 기준값 / 환산규칙
  └─ 영역별 가중치
  └─ 최종점수
  └─ 최종등급
